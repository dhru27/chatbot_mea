# Additional MEA Assistant notes

Add future verified chatbot data here, or create more markdown files in this same folder.

Recommended format:

## Source

- Title:
- URL or file name:
- Last verified:
- Who verified:

## Facts to add

- Add concise facts here.
- Prefer official sources such as ASC, Academic Office, Mechanical Engineering department pages,
  faculty/course pages, MEA verified docs, or student council verified notes.
- If the source is not public, mention who provided it and when it was verified.

## Course/instructor mappings
